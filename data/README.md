This folder contains the **dataset** used in the **classification** and **regression models**.

- [**Boston.csv**](https://github.com/4709625727/model-interpretability-for-machine-learning-models/blob/master/data/Boston.csv) is **used for regression** models. This dataset was taken from [**UCI Machine Learning Repository**](https://archive.ics.uci.edu/ml/index.php) from this [**link**](https://archive.ics.uci.edu/ml/datasets/Housing).

- [**mushrooms.csv**](https://github.com/4709625727/model-interpretability-for-machine-learning-models/blob/master/data/mushrooms.csv) is **used for classification** models. This dataset was taken from [**UCI Machine Learning Repository**](https://archive.ics.uci.edu/ml/index.php) from this [**link**](https://archive.ics.uci.edu/ml/datasets/Mushroom).
